## 📝 Типичные процессы

### Как работает система создания привычки:

```
/add → выбрать частоту → (если weekly/monthly: выбрать дни)
    → спросить опциональные данные (описание, цель)
    → показать подтверждение
    → создать привычку
```

### Как работает выполнение привычки:

```
/today или /habits → выбрать привычку
    → система проверяет: активна ли на сегодня?
    → если да: показать кнопки Выполнить/Пропустить
    → при клике "Выполнить":
        1. Логирует выполнение
        2. Показывает счётчик серии
        3. Спрашивает "Добавить комментарий?"
        4. Если "Да" → ждёт ввода
        5. Сохраняет комментарий
```
