# 🎯 Примеры использования HobitsBot

## Примеры сценариев работы с ботом

### Пример 1: Создание первой привычки

```
Пользователь: /add
Бот: ✏️ Введите название новой привычки:
     Например: Зарядка, Чтение, Медитация

Пользователь: Зарядка
Бот: ✨ Отлично! Привычка: Зарядка
     Выберите частоту:
     [📅 Ежедневно] [📆 Еженедельно] [📊 Ежемесячно]

Пользователь: [Нажимает на 📅 Ежедневно]
Бот: 🎉 Привычка создана!
     Зарядка
     📅 Ежедневно
     Теперь я буду отправлять вам напоминания. Удачи! 🚀
```

## API интеграция (примеры curl)

### Создание привычки через HTTP (если добавить REST API)

```bash
curl -X POST http://localhost:8080/api/habits \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1,
    "name": "Зарядка",
    "frequency": "daily",
    "description": "30 минут упражнений"
  }'
```

### Логирование выполнения через HTTP

```bash
curl -X POST http://localhost:8080/api/habits/1/complete \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1,
    "comment": "Выполнил 30 минут"
  }'
```

## Примеры обработки ошибок

```
❌ Ошибка
Привычка не найдена
Пожалуйста, попробуйте позже или используйте /help.

❌ Ошибка
Название не может быть пустым. Попробуйте снова.

❌ Ошибка
Название слишком длинное (макс. 100 символов)

❌ Ошибка
не удалось получить привычки
Пожалуйста, попробуйте позже или используйте /help.
```

## Примеры состояний пользователя

```
Состояния пользователя в контексте:

1. waiting_habit_name - Ожидание названия привычки
2. waiting_frequency - Ожидание выбора частоты
3. waiting_weekdays - Ожидание выбора дней недели
4. waiting_monthdays - Ожидание выбора дней месяца
5. waiting_reminder_time - Ожидание выбора времени напоминания
6. waiting_confirmation - Ожидание подтверждения

Данные в контексте:

- habit_name - Название привычки
- habit_frequency - Частота выполнения
- selected_weekdays - Выбранные дни недели
- selected_monthdays - Выбранные дни месяца
- reminder_time - Время напоминания
- habit_id - ID текущей привычки
```
