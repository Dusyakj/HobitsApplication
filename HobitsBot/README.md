# 🎯 HobitsBot - Telegram Bot для отслеживания привычек

HobitsBot - это полнофункциональный Telegram бот для управления привычками с поддержкой gRPC интеграции.

## ✨ Возможности

- ✅ **Управление привычками** - создание, редактирование, удаление привычек
- 📅 **Гибкое планирование** - ежедневные, еженедельные и ежемесячные привычки
- 🔔 **Напоминания** - автоматические напоминания о необходимых привычках
- 📊 **Статистика** - отслеживание прогресса и достижений
- 🎨 **Удобный интерфейс** - кнопки, клавиатуры и интуитивное управление
- 🔥 **Серии** - отслеживание непрерывных серий выполнения привычек
- 🏆 **Достижения** - уведомления о новых достижениях
- 🌍 **Поддержка языков** - автоматическое определение языка пользователя

## 🚀 Быстрый старт

### Требования
- Go 1.24+
- Telegram Bot Token (получить от @BotFather)
- Запущенный HobitsService gRPC сервер

### Установка

1. Клонируйте репозиторий
```bash
cd HobitsBot
```

2. Установите зависимости
```bash
go mod download
```

3. Создайте `.env` файл на основе `.env.example`
```bash
cp .env.example .env
```

4. Отредактируйте `.env` и добавьте ваш токен:
```
TELEGRAM_BOT_TOKEN=your_bot_token_from_botfather
GRPC_SERVER_ADDR=localhost:50051
LOG_LEVEL=info
```

5. Запустите бот
```bash
go run cmd/main.go
```

## 📋 Команды бота

### Основные команды
- `/start` - Начало работы и инициализация
- `/help` - Справка по использованию бота
- `/habits` - Просмотр всех ваших привычек
- `/add` - Добавить новую привычку
- `/today` - Показать напоминания на сегодня
- `/stats` - Просмотреть статистику по привычкам

### Взаимодействие с кнопками
После выполнения команд бот предлагает кнопки для удобного управления:

**При просмотре привычки:**
- ✅ Выполнено - отметить привычку как выполненную
- ⏭️ Пропустить - пропустить привычку на этот день
- 📝 Комментарий - добавить комментарий к выполнению
- 📊 Статистика - просмотреть статистику по привычке

**При добавлении привычки:**
- Выберите частоту (ежедневно, еженедельно, ежемесячно)
- Для еженедельных привычек выберите дни недели
- Для ежемесячных привычек выберите дни месяца
- Установите время напоминания

## 🔧 Конфигурация

Конфигурация задается через переменные окружения в файле `.env`:

```env
# Telegram Bot Token от @BotFather
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklmnoPQRstuvWXYZabcdefgh

# Адрес gRPC сервера HobitsService
GRPC_SERVER_ADDR=localhost:50051

# Уровень логирования (debug, info, warn, error)
LOG_LEVEL=info
```

## 🤝 Интеграция с HobitsService

Bot подключается к HobitsService через gRPC и использует следующие сервисы:
- **UserService** - для управления пользователями
- **HabitService** - для работы с привычками
- **LogService** - для логирования выполнений
- **ReminderService** - для работы с напоминаниями

## 💬 Пользовательские сценарии

### Сценарий 1: Создание новой привычки
1. Пользователь нажимает `/add` или кнопку "➕ Добавить"
2. Бот просит название привычки
3. Пользователь вводит название
4. Бот предлагает выбрать частоту
5. После выбора частоты может потребоваться выбор дней
6. Привычка сохраняется в базу данных

### Сценарий 2: Выполнение привычки
1. Пользователь нажимает `/today` для просмотра напоминаний
2. Видит список привычек на сегодня
3. Нажимает на привычку
4. Нажимает "✅ Выполнено" или "⏭️ Пропустить"
5. Бот сохраняет выполнение и обновляет серию

### Сценарий 3: Просмотр статистики
1. Пользователь нажимает `/stats`
2. Видит общую статистику
3. Может выбрать период (неделя, месяц, все время)
4. Видит график и процент выполнения

## 📊 Форматирование сообщений

Бот использует красивое форматирование с:
- Emoji для визуализации состояний
- Markdown для текстового стиля
- Inline кнопки для быстрых действий
- Reply кнопки для основного меню
- Прогресс-бары для показания статистики

## 🐛 Обработка ошибок

- Все ошибки обрабатываются и логируются
- Пользователю показываются понятные сообщения об ошибках
- Автоматическое восстановление при потере соединения
- Graceful shutdown при завершении приложения

## 🔐 Безопасность

- Токен бота хранится в переменной окружения
- gRPC соединение может быть защищено TLS
- Контексты пользователя имеют TTL и удаляются автоматически
- Восстановление от паник в горутинах обработки обновлений

## 📝 Логирование

Бот логирует все важные события с разными уровнями:
- `DEBUG` - детальная информация
- `INFO` - основная информация
- `WARN` - предупреждения
- `ERROR` - ошибки

## 🚀 Развертывание

### Docker
```dockerfile
FROM golang:1.24 AS builder
WORKDIR /app
COPY . .
RUN go build -o hobitsbot cmd/main.go

FROM ubuntu:latest
RUN apt-get update && apt-get install -y ca-certificates
COPY --from=builder /app/hobitsbot /hobitsbot
COPY .env /
CMD ["/hobitsbot"]
```

### Kubernetes
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: hobitsbot
spec:
  replicas: 1
  selector:
    matchLabels:
      app: hobitsbot
  template:
    metadata:
      labels:
        app: hobitsbot
    spec:
      containers:
      - name: hobitsbot
        image: hobitsbot:latest
        env:
        - name: TELEGRAM_BOT_TOKEN
          valueFrom:
            secretKeyRef:
              name: telegram-secret
              key: token
        - name: GRPC_SERVER_ADDR
          value: "hobits-service:50051"
```
